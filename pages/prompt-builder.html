🛡

Security & Privacy

Built with security in mind — your credentials do not belong in your projects or public website code.

Secure API Connections

Published-site AI and email features are designed to use a separate secure backend instead of exposing secret keys in GitHub Pages.

Encrypted Local API Vault

Personal API keys can be stored in an AES-GCM encrypted local vault protected by a master password that Prompt Builder does not save.

Protected Project Files

Exported project files contain project settings and prompts, not API keys or passwords.

Secure Website Services

Referral, support, feedback, screenshot, and site-reference submissions are designed to pass through the owner-configured backend.

User-Controlled Storage

Local drafts and saved projects remain in the browser unless the user explicitly exports or submits something.

Privacy-Focused Design

Payment pages display cropped QR codes rather than unnecessarily publishing account usernames or phone numbers.
