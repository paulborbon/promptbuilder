Mock Ticket

A simplified example of how I structure an IT support case.

INC0012345

User cannot access Outlook Online

In Progress
PriorityHigh
CategoryMicrosoft 365
ServiceExchange Online
ImpactSingle user

Approach

  1. Confirm scope, recent changes and exact error.
  2. Check Microsoft 365 service health and user sign-in status.
  3. Validate licensing, mailbox state and relevant policies.
  4. Test browser/session isolation and compare Outlook desktop/mobile behavior.
  5. Review logs or headers as appropriate.
  6. Document findings, resolution and prevention steps.

Communication

Keep the user informed with concise updates, avoid jargon when possible, and document the troubleshooting path so the next engineer can continue without repeating work.
